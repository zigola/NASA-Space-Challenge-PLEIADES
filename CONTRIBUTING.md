# Contributing to PLEIADES

Thank you for helping improve the project.

## Before contributing

1. Read the README and relevant documentation.
2. Open an issue for substantial changes or new features.
3. Do not include API keys, private data, unlicensed datasets, or generated secrets.
4. Confirm that sample data and code can legally be shared.

## Pull requests

- Keep changes focused and explain the motivation.
- Add or update tests for behavior changes.
- Update documentation when commands or behavior change.
- Run `pytest -q` before submitting.
- Clearly label experimental or unvalidated functionality.

## Scope

Prioritize reproducibility, data validation, transparent risk logic, accessibility, and safe defaults. Avoid presenting research prototypes as operational emergency systems.
