# Data Dictionary

## Normalized FIRMS fields

- latitude: decimal latitude
- longitude: decimal longitude
- brightness: brightness temperature proxy
- confidence: confidence score
- frp: fire radiative power
- acq_date: acquisition date
- acq_time: acquisition time
- satellite: logical source (for example VIIRS or MODIS)
- instrument: normalized instrument name
- daynight: daytime or nighttime flag
- timestamp: merged datetime
- source_file: original CSV file
