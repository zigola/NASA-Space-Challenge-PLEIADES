# Demo Guide

1. Install dependencies.
2. Start the app with `streamlit run app.py`.
3. Upload a local FIRMS CSV or use the synthetic demonstration mode.
4. Use the region filter to focus on Morocco-Rif or a global window.
5. Review normalized detections, harmonized events, and IoT alerts.
6. Use the replay and risk interfaces to explain the platform to judges.

The app is intentionally offline-ready and does not require a live NASA API.
